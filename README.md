# Fluxplane Plugins

This repository contains plugin implementation modules that use the reusable
`github.com/fluxplane/fluxplane-plugin` SDK.

Current migrated modules:

- `atlassian`
- `asterisk`
- `docker`
- `gitlab`
- `grafana`
- `kubernetes`
- `loki`
- `ollama`
- `prometheus`
- `slack`
- `sql`
- `system`
